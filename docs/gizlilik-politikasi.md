# Derin Gizem Yükleyici — Gizlilik Politikası

Son güncelleme: 23 Kasım 2026

"Derin Gizem Yükleyici", Derin Gizem YouTube kanalının sahibi tarafından, **yalnızca kendi kanalına**
video yüklemek için kullanılan özel bir araçtır. Başka kullanıcılara hizmet vermez.

## Hangi verilere erişilir?
- Araç, YouTube Data API üzerinden yalnızca kanal sahibinin kendi kanalına video, kapak fotoğrafı ve
  altyazı yükler ve yüklenen videonun durumunu kontrol eder.
- Başka hiçbir kişinin verisine erişilmez, veri toplanmaz, satılmaz veya üçüncü kişilerle paylaşılmaz.

## Veriler nerede saklanır?
- Yetkilendirme bilgileri (erişim anahtarları), yalnızca kanal sahibinin GitHub deposunun şifreli
  "Secrets" bölümünde saklanır ve kod ya da kayıtlarda görünmez.
- Yüklenen videolar YouTube'da yayınlanır; geçici üretim dosyaları yükleme doğrulandıktan sonra silinir.

## Erişimin kaldırılması
Kanal sahibi, Google hesabı ayarlarındaki "Üçüncü taraf erişimi" bölümünden bu aracın erişimini
dilediği zaman kaldırabilir.

## YouTube Hizmet Şartları
Bu araç YouTube API Hizmetlerini kullanır. YouTube Hizmet Şartları: https://www.youtube.com/t/terms ·
Google Gizlilik Politikası: https://policies.google.com/privacy
